# Sinister.Life Launcher

Download: [Neueste Version](https://github.com/iSkeezer/sinister-launcher/releases/latest)

- **Setup** (empfohlen): installiert den Launcher und aktualisiert sich automatisch.
- **Portable**: einzelne Datei ohne Installation (keine automatischen Updates).

Windows zeigt beim ersten Start evtl. „Unbekannter Herausgeber“ → „Weitere Informationen“ → „Trotzdem ausführen“.
